# Security

Please do not report security problems in a public issue. Use [private vulnerability reporting](https://github.com/noah-thing/openroll/security/advisories/new) on GitHub instead, with steps to reproduce and the version you tested. You will get an answer within a few days.

Areas where a report matters most:

- The update path: download, checksum check and install.
- The AI control socket and its token.
- Opening project files or media made by someone else.
